# Python Mini-Projects

A collection of small Python projects I built on my own, mostly out of curiosity
and for fun while learning to program. They all run in the command line and use
only the Python standard library.

I'm putting them on GitHub now because I'm applying for a dual study program in
software development, and I wanted a place to keep and share the things I've
actually built myself over the years — not just coursework.

The code is kept as I originally wrote it. It's not always the most elegant, but
it's authentic and it works. Where I improved something, I say so explicitly.

## Projects

### Number System Converter
`number_system_converter.ipynb`

One of my very first projects, from high school. We had just learned about the
ASCII table and how computers represent numbers in different bases, and I wanted
to understand how a conversion works under the hood. So instead of using Python's
`bin()` or `hex()`, I implemented the math by hand. It converts between decimal,
binary, hexadecimal and octal, with input validation.

### Tic-Tac-Toe
`tic_tac_toe.ipynb`

A two-player Tic-Tac-Toe game I made when I was bored in class and wanted to see
if I could build a full working game on my own. Players take turns picking cells
on a 3x3 grid and the program checks for a winner after each move.

### Casino Game
`casino_game.ipynb`

A text-based betting game to practice loops, conditions and input handling. You
place bets and guess a number between 0 and 49, with different payouts depending
on how close you get. The only change from my original version is a small bug fix
(the random target range was off by one).

## Technologies

Python 3 — standard library only.

## Note

These were learning projects, written at different points in time. I know some of
the code could be shorter or more optimized today, but I chose to keep it
authentic rather than rewrite it. What matters to me is that I built each of these
from scratch and understand exactly how they work.
